# OTW Coffee Run — demo

Versi web untuk dicoba langsung di browser:
**https://mochrezarizaldi.github.io/otw-coffee-run-demo/**

Repo ini hanya berisi hasil build (tanpa kode sumber).

## Cara bermain

- Tekan **Main**. Sentuh atau klik layar untuk melompat; tahan untuk lompatan lebih tinggi.
- Kumpulkan cup kopi untuk skor dan hindari rintangan di jalan.
- Di HP, putar layar ke posisi **landscape** (mendatar). Di Android (Chrome), game masuk
  layar penuh saat **Main** ditekan.
- Di iPhone, Safari tidak mengizinkan layar penuh untuk halaman web. Agar tampil tanpa
  bilah browser: tombol Bagikan → **Tambahkan ke Layar Utama**, lalu buka dari ikon itu.

## Catatan

- Ini versi demo dengan server tiruan: leaderboard berisi pemain contoh, dan skor hanya
  tersimpan di browser masing-masing.
- Setiap versi ada di foldernya sendiri (`v1/`, `v2/`, ...); halaman utama selalu membuka
  versi terbaru.
